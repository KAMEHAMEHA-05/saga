# Saga

**A dialogue engine for NPCs that actually remember things.**

Saga is an open-source dialogue engine for creating **conversational game worlds** where NPCs can talk about what they know, remember, and experience rather than simply responding from a static character prompt.

The idea is simple:

> **NPCs shouldn't just have personalities. They should have minds.**

Saga is designed around the idea that an NPC should be able to access its own knowledge when a player speaks to it, allowing conversations to feel grounded in the world around them.

A guard can know about the people they've met.  
A merchant can know about the caravan they saw yesterday.  
A villager can remember a rumor they heard.  
And two NPCs can know completely different things about the same world.

The goal is to make conversations feel less like talking to an AI assistant and more like **talking to someone who actually lives there.**

---

## What is Saga?

Saga is being built as a foundation for **real-time NPC conversations in games**.

Instead of giving every NPC an enormous prompt containing everything they could possibly know, Saga treats knowledge as something an NPC can **access when it becomes relevant**.

This allows game worlds to contain large amounts of information without requiring every NPC to carry the entire world inside its context.

The result is a system where:

- NPCs can have different knowledge of the same world.
- Conversations can remain grounded in established facts.
- NPCs can respond based on what is relevant to the current conversation.
- Knowledge can persist beyond a single interaction.
- Different NPCs can eventually develop distinct personalities and ways of speaking.

---

## The Vision

Most game NPCs are either completely scripted or given a language model with a character description.

Saga explores something in between:

**NPCs with actual knowledge of the world they inhabit.**

The long-term goal is a game world where conversations are not written individually for every possible situation.

Instead, the world provides the knowledge, the NPC provides the perspective, and the conversation emerges naturally.
